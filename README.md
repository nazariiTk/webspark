# Webspark Pathfinder

Flutter тестове завдання: пошук найкоротшого шляху на сітці з перешкодами з інтеграцією REST API.

## Стек та архітектура

* **Flutter 3.50 / Dart 3.14**
* **State Management:** `flutter_bloc` (`Cubit`) + `equatable`
* **Мережевий шар:** `dio` (підтримка повного URL із GET query-параметрами)
* **Локальне сховище:** `shared_preferences`
* **Архітектура:** Clean Architecture (розділення на `domain`, `data`, `presentation`) без пакетів кодогенерації.

## Алгоритм пошуку найкоротшого шляху

Використано власну ООП-реалізацію пошуку в ширину (**BFS — Breadth-First Search**) на 8 напрямках (горизонталь, вертикаль, діагоналі):
* `GridPoint` — координати `(x, y)` з серіалізацією у формат `"(x,y)"` та `{"x": "...", "y": "..."}`.
* `GridMap` — квадратна матриця (від 2×2 до 99×99) з перевіркою меж і перешкод (`X`).
* `PathFinder` / `BfsShortestPathFinder` — інтерфейс і реалізація алгоритму пошуку мінімального шляху з відновленням маршруту.

## Екрани

1. **Home screen** — введення та валідація API URL, локальне збереження, запуск обробки.
2. **Process screen** — отримання завдань (`GET`), розрахунок із прогресом у відсотках (`0%–100%`) і відправка результатів (`POST`).
3. **Result list screen** — перелік розрахованих шляхів у форматі `(x1,y1)->(x2,y2)`.
4. **Preview screen** — візуалізація сітки з координатами та кольоровим кодуванням:
   * Старт: `#64FFDA`
   * Фініш: `#009688`
   * Перешкода (`X`): `#000000`
   * Найкоротший шлях: `#4CAF50`
   * Порожня клітинка: `#FFFFFF`
